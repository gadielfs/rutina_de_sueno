# Horario de sueño

Ventana objetivo: **22:30 – 07:00** (8 h 30 min). Misma hora todos los días, también el fin de semana.

## Línea de tiempo

| Hora | Acción |
|------|--------|
| 17:00 | Última cafeína (café, té fuerte, refresco, energética) |
| 19:00 | Cena ligera |
| 20:30 | Cerrar tareas pesadas / estudio intenso |
| 21:15 | Apagar pantallas (teléfono fuera de la habitación) |
| 21:30 | Ducha tibia |
| 21:50 | Lectura en papel o respiración lenta |
| 22:20 | Luces bajas |
| 22:30 | A dormir |
| 07:00 | Despertar + 5–10 min de luz natural |

## Si un día se atrasa

No duermas hasta mediodía. Levántate cerca de las 07:00 y adelanta un poco la noche siguiente.
